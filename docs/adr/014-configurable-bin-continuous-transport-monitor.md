# ADR 014：可配置单物体 bin 与持续搬运监测

- 日期：2026-10-03
- 状态：已采纳
- 关联：ADR 009、010、011、012、013；Week 4 Stage 6

## 背景

Stage 5 已完成默认视觉抓放，暂停运输视觉使 pose 不更新，也无法独立发现闭爪滑落。用户将目标调整为 CLI 配置单 box/bin 位置和旋转、真实入 bin，并要求遮挡和持续偏离不能单独停机，可疑偏离与疑似掉落合并。多物体、多颜色暂停。

## 决策

共享 SceneConfig 定义 box/bin xyz/rpy、自动支撑高度和几何检查，同一配置驱动 MuJoCo reset、已知 bin 视觉过滤与任务目标。bin 为静态底板和四壁，支持受限倾斜，不新增模型自由度。

视觉在附着期持续运行。executor 用合格视觉和同时间 TCP 初始化固定 TCP→box 变换，执行位置随当前 TCP 推算，视觉独立监测；禁止从真值 box TF 初始化视觉推算，禁止将持续偏离自动融合进变换。估计 frame 为 box_estimated，保留独立真值 box。

运输状态为 NORMAL、VISION_UNAVAILABLE、ANOMALY_PENDING、CONFIRMED_DROP。遮挡/拒绝和单独偏离继续执行；可靠分离、下移及持续下坠/支撑启发式满足门限才锁存确认掉落，保持当前关节/宽度并终止，零重试。主动 OPEN 命令与实际开启反馈共同建立释放边界。最终成功依赖释放后的新测量、完整旋转盒体包含及多帧稳定性，不只检查 XY。

## 权衡与后果

固定变换可保留初始误差，却使独立残差能够揭示滑移；在线融合可能改善精度，也可能隐藏异常。已知 bin 几何便于当前单物体任务，但不是视觉定位 bin。离桌几何使用可见顶面假设，不支持任意倾斜完整 6D 恢复。bridge 附着仍使用仿真真值/接触。

完全遮挡不能确认掉落，支撑先验不是物理接触证明；合成掉落注入只验证监测和终止链。释放时适配层清历史可能丢失迟到的释放前异常，异步边界仍待验证。真机安全停止、VLA 数据导出与多物体任务不属于本决策。

## 验证与事实维护

配置、旋转几何、监测状态与释放反馈时间顺序由单测验证；真实 MuJoCo 的 oracle/vision 默认和配置回归、故障注入、CDR 回放及限制记录在 [Week 4 Stage 6](../../Job_guides/my_study/week4.md#stage-6可配置单物体入-bin-与搬运监测)。当前默认值与接口由 [architecture.md](../architecture.md) 维护，后续决策变更新增 ADR，不修改旧快照。
