# ADR 010：以夹持证据切换视觉与 TCP 附着模型

## Status

已决定，待按新计划实施与验收（2026-10-01）。细化并调整 [ADR 009](009-robot-aware-stateful-vision.md) 的夹持运动模型与准入条件；保留机器人掩膜、证据四态、oracle 隔离和最终重新实测要求。ADR 009 保持历史快照不修改。

## Context

机器人掩膜不能恢复被夹爪遮住的物体像素。Stage 5 首版原型增加候选关联和有界预测，要求先看到物体与 TCP 共同运动才启用附着模型；实际抓取可能在共同运动可见前就完全遮挡目标。

用户提出判断夹住后锁定 TCP 相对位姿，以及是否还需要视觉跟踪。附着模型可支持遮挡期间搬运，但闭爪命令、进入 GRASP、轨迹执行完成不能直接证明夹持；摩擦夹持也允许滑移。公开几何工具不能替代这一证据判断，任务编排框架不是本阶段所需工具。

## Decision

物体状态估计继续归属 `mujoco_perception`。位姿证据 MEASURED/PREDICTED/OCCLUDED/REJECTED 与夹持状态分开表达；夹持状态有独立的准入依据、时间和失效原因。`task_executor` 消费结果，不另建夹持判断或物体跟踪；`EpisodeController` 继续拥有任务生命周期。

抓取前以视觉候选、已知尺寸、质量和时序门限维护目标身份。夹持判断综合实际夹爪宽度、稳定时间、TCP 与目标关系、最近可靠视觉测量及可用反馈；不要求先看到共同运动，不以 phase 或闭爪命令作为充分条件。当前没有可靠力反馈时明确能力边界，不借用 oracle pose 或仿真接触位补足 vision 证据。可见共同运动可作为辅助验证。

夹持证据门通过后，用可靠目标测量及同帧 TCP 建立 `T_tcp_object = inverse(T_world_tcp) × T_world_object`，后续以当前 `T_world_tcp × T_tcp_object` 预测。测量与确认夹持时间不同时，验证测量年龄和期间目标运动假设，不能无条件拼接旧物体 pose 与当前 TCP。若采用 TCP 中心等抓取几何先验，另行标明依据与不确定性，不标成视觉测量。

夹持后 TCP 模型为主；有当前目标点支持才输出 MEASURED，并以重见测量检查附着偏差、校正或报告滑移。张爪、反馈异常、关联冲突、预测过期、reset/重启使附着失效。释放后重新关联并实测，不把解除前的 TCP pose 当作落点。

支撑、夹持、释放采用分别验证的预测时限与不确定性增长。夹持期不沿用统一短遮挡时限，也不无限续期。完全遮挡时不能确认没有滑落；预测不得更新最近实测时间、伪造测量残差或独自触发物理成功。最终成功要求释放且机械臂移开后重新视觉测量。

复用 PCL 分割/几何算法，在局部遮挡回放上比较 OBB 与 PCL ICP/GICP 的误差、退化拒绝和耗时后决定配准方案。粒子滤波跟踪仅在回放证明必要时引入。目标身份、夹持证据、模型切换和生命周期由项目维护。本阶段不引入 MoveIt 或 MTC；TCP 附着不依赖这些工具。

## Alternatives

全程要求可见共同运动，证据直接但抓取遮挡时难以启动附着。缓存首帧并永久随 TCP 搬运，会掩盖空抓、滑落和陈旧测量。复杂视觉粒子滤波仍无法从完全不可见的物体确认持物，且增加调参成本。任务编排框架不能替代夹持检测，并与当前 executor 存在职责重叠。

## Consequences

跟踪保留目标身份、测量历史和重见关联，但夹持期不强制连续视觉估计。代价是夹持/附着契约、分别标定运动模型及明确不可见滑落盲区。稳定宽度也可能来自错误物体或阻塞，不能承诺单凭宽度确认指定目标。

Stage 5 负责状态估计与验证，Stage 6 负责按证据调整 FSM 与成功门。已有原型须按此决策修改；其构建/测试通过和 oracle 搬运记录不等于新策略或视觉抓放验收。具体计划和原始追问见 [Week 4 Stage 5](../../Job_guides/my_study/week4.md#25-stage-5目标关联与遮挡状态估计)。

## Verification

待完成空抓、错误目标、夹爪阻塞、测量陈旧、夹持后完全遮挡、可见/不可见滑落、张爪解除、释放重见和跨生命周期序列测试。断言夹持不能由预测自证，附着建立/解除原因可观测，无点支持不得发布 MEASURED，年龄、不确定性与时限有效。不可见滑落测试记录检测盲区以及超时和最终重见门。

待在同一回放比较 OBB/PCL 配准并验证各运动模型参数；实际运行报告各 phase 四态计数、夹持/附着转换原因和 p50/p95 延迟。Stage 6 再做完整 vision 抓放与失败注入，成功须有释放后的新实测证据。
