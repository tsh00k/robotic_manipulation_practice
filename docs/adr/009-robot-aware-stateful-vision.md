# ADR 009：用机器人几何与时序证据完成视觉抓放

## Status

已决定，待实施（2026-09-30）。对应 Week 4 Stage R1~R3；本文不把规划中的行为写成已验证事实。

## Context

Stage Q 的视觉节点按单帧 RGB-D 去桌面、取最大点簇、拟合盒体 OBB。Stage R 让任务层消费该 pose，但每个新视觉样本只要被拒绝，就立即结束 episode。已实测初始 `accepted=true` 的位姿进入 `PREGRASP`；机械臂靠近后与盒体形成混合点簇，估计器报 `MODEL_EXTENT_MISMATCH`，任务以 `VISION_REJECTED` 结束。当前只证明了停止语义，没有完成 vision 模式抓放。

单次初始位姿可以给静止盒体生成抓取目标，但不能观测其抬升、滑落或放置。现有 `makeObservationSnapshot()` 把同一物体 pose 同时用于 waypoint、盒体高度、盒体到 TCP 距离和最终落点验收。只缓存首帧并让后续帧继续使用它，会把过期规划坐标误作当前物理证据。`BridgeObservation` 还含仿真物体真值和接触位；它们不得在 vision 模式下隐式决定在线成功。

## Decision

视觉能力继续归属独立的 `mujoco_perception` 包，`mujoco_bridge` 保持相机和机器人状态源。感知输入使用 RGB-D、CameraInfo、同帧生命周期键、关节/夹爪状态、现有 TF 和经实测核对的机器人 link 几何。感知节点不读取 `BridgeObservation.object_pose` 或仿真双指接触来检测、跟踪或确认物体；oracle 仅用于隔离的离线评测。

感知处理分三层：

1. 根据同帧机器人 link 位姿与几何，在相机平面渲染机器人预测深度。只过滤观测深度与预测机器人表面相符的像素，保留机器人轮廓内但更靠近相机的物体点；掩膜及容差必须可视化和定量验证。缺失对应位姿或模型失配时拒绝该帧，不使用旧 TF 静默补齐。
2. 在剩余点云里用盒体尺寸、几何残差和轨迹门限做候选关联，不再默认选最大簇。桌面上的物体可以使用支持平面先验；离桌后不能继续把盒体 z 锚定到桌面。模型不匹配、错误身份和目标丢失分别输出可诊断原因。
3. 建立随 session/generation 清空的时序跟踪。`MEASURED` 需要本帧物体像素支撑；`PREDICTED` 只能在曾有可靠测量、物体运动模型成立且年龄/不确定性未超限时给出有界 pose；`OCCLUDED` 表示没有可执行 pose；`REJECTED` 表示输入或几何证据冲突。预测年龄与不确定性随无测量时间增长。完全遮挡时不能宣称单相机确认了持物或未滑落。

扩展 `VisionObjectPose` 的状态、最近实测时间/序号、预测年龄和不确定性元数据，保留 bridge session、generation、当前样本序号与拒绝原因。旧 `accepted` 字段只对合格的 `MEASURED` 为 true；旧消费者遇到 `PREDICTED/OCCLUDED/REJECTED` 继续 fail closed。新任务适配层按显式状态处理，不能用预测 pose 冒充实测 pose，也不能把预测残差写成测量残差。

任务层只做必要的证据门适配：继续用新鲜关节/TCP/夹爪状态和 `EpisodeController` 的 reset、generation、sequence 生命周期；允许有时限的预测支持运动，超时或冲突必须停下。当前依赖物体高度、相对 TCP 距离和落点的 FSM 判据要区分测量与预测；预测不能单独触发“已抬升”“未滑落”或 `DONE`。释放并移开机械臂后，必须由新的 `MEASURED` 位姿验证落点；未能重见报告未验证或失败。vision 模式的在线成功判据不得借用仿真物体真值或接触位。oracle 模式保留为独立基线。

## Alternatives

只在 executor 锁定首帧视觉位姿、忽略后续拒绝，可以尽快让固定场景沿既有轨迹运动，但遮挡期间和最终落点仍缺独立证据，且把规划先验扩展成物理成功依据。用户决定优先建设可迁移的机器人感知与时序跟踪能力。

只加机器人掩膜、不加目标关联与时序状态，可以减少混簇，但在局部/完全遮挡、掉落、释放后重现时仍无法区分目标与机器人，也无法表达没有测量的时间。把预测一律发布为 `accepted=true` 会掩盖这一缺口。

新增相机或改变观察位姿可减少不可观测区，但当前先用单相机验证几何掩膜与跟踪边界；完全遮挡仍需显式超时或主动重新观察，不能假设算法能恢复不可见物体。

## Consequences

这一决策改变了 Stage R 的“逐帧估计拒绝即终止”入口语义和视觉成功证据，不替换 ADR 003 的生命周期协议或 ADR 004 的控制器所有权。代价是模型几何对齐、掩膜渲染、跟踪状态、消息扩展、任务证据门与重放工具的维护成本。`mujoco_bridge` 不新增视觉算法或第二套 TF 发布者。

当前 Stage R 的 `VISION_REJECTED` smoke test 仍是历史实测，不能再作为视觉抓放完成的验收。R1~R3 的目标与实测分开记录；Week 4.5 只接收完成验证后的证据状态契约。
